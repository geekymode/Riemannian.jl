API reference

Riemannian.Riemannian — Module
Riemannian

A study kit for the Riemann Hypothesis: from primes and the Euler product, through analytic continuation and the functional equation, to trivial and nontrivial zeros, explicit formulas, random-matrix statistics, equivalent criteria and recent results.

The numerical core has no plotting dependency. Loading CairoMakie activates the plotting extension (plot_* functions and gallery).

Start with explain() for the list of topics, or explain(:trivial_zeros) etc.

Riemannian.bernoulli — Function
bernoulli(n) -> Rational{BigInt}

Bernoulli number Bₙ (convention B₁ = −1/2). Exact, cached. B₂ = 1/6, B₄ = −1/30, … — they give ζ(2k) and ζ(1−2k) exactly.

source
Riemannian.zeta_even_exact — Function
zeta_even_exact(n) -> Rational{BigInt}

The rational r with ζ(2n) = r · π^{2n} (Euler, 1735/1740): ζ(2n) = (−1)^{n+1} B₂ₙ (2π)^{2n} / (2 (2n)!). zeta_even_exact(1) == 1//6 (Basel problem).

source
Riemannian.zeta_negint_exact — Function
zeta_negint_exact(n) -> Rational{BigInt}

ζ(−n) = (−1)ⁿ Bₙ₊₁ / (n+1) for n ≥ 0. ζ(0) = −1/2, ζ(−1) = −1/12, ζ(−2k) = 0 (trivial zeros).

The zeta function and relatives

Riemannian.zeta — Function
zeta(s)

The Riemann zeta function for any complex s ≠ 1 (generic float type, incl. BigFloat).

  • Re s ≥ 0: Euler–Maclaurin (zeta_em).
  • Re s < 0: functional equation ζ(s) = χ(s) ζ(1−s); exact zero at negative even integers, exact Bernoulli values at negative odd integers.

Real input gives a real result.

source
Riemannian.zeta_em — Function
zeta_em(s; N, M)

ζ(s) by Euler–Maclaurin summation:

ζ(s) = Σ{n<N} n^{-s} + N^{1−s}/(s−1) + N^{-s}/2 + Σ{k=1}^{M} B₂ₖ/(2k)! · s(s+1)⋯(s+2k−2) · N^{−s−2k+1} + R.

The right side is analytic for all s ≠ 1, so this formula is an analytic continuation. Defaults pick N, M so the error is near machine precision for the float type of s (works with BigFloat). Best for Re s ≥ 0; zeta reflects otherwise.

source
Riemannian.zeta_borwein — Function
zeta_borwein(s; n = 60)

ζ(s) via P. Borwein's accelerated η-series, ζ(s) = η(s)/(1 − 2^{1−s}). Accurate for Re s > 0 and modest |Im s| (error grows like e^{π|t|/2}); a nice illustration that a convergent series already continues ζ to 0 < Re s < 1.

source
Riemannian.dirichlet_eta — Function
dirichlet_eta(s)

Dirichlet eta η(s) = Σ (−1)^{n−1} n^{-s} = (1 − 2^{1−s}) ζ(s), entire. η(1) = log 2.

source
Riemannian.chi_factor — Function
chi_factor(s)

χ(s) = 2ˢ π^{s−1} sin(πs/2) Γ(1−s), the factor in the functional equation ζ(s) = χ(s) ζ(1−s). On the critical line |χ(1/2+it)| = 1. The sin(πs/2) factor vanishes at s = −2, −4, …: these are the trivial zeros.

source
Riemannian.completed_zeta — Function
completed_zeta(s)

Λ(s) = π^{−s/2} Γ(s/2) ζ(s), satisfying the symmetric functional equation Λ(s) = Λ(1−s). The Γ(s/2) poles cancel the trivial zeros, so Λ's zeros are exactly the nontrivial ones.

source
Riemannian.xi — Function
xi(s)

Riemann's ξ(s) = ½ s(s−1) π^{−s/2} Γ(s/2) ζ(s): entire, ξ(s) = ξ(1−s), ξ(s̄) = conj ξ(s), zeros = nontrivial zeros of ζ. Real on the critical line and on the real axis.

source
Riemannian.Xi — Function
Xi(t)

Riemann's Ξ(t) = ξ(1/2 + it), a real even function of real t. RH ⇔ all zeros of Ξ are real. Decays like t^{7/4} e^{−πt/4}, so it underflows in Float64 for t ≳ 900.

source
Riemannian.loggamma_c — Function
loggamma_c(z)

Complex log-Gamma. For Re z ≥ 1/2 this is the analytic branch (continuous in z), which matters for the Riemann–Siegel theta function; for Re z < 1/2 the reflection formula is used and the result is only correct modulo 2πi (fine for exp).

source
Riemannian.KNOWN_ZEROS — Constant
KNOWN_ZEROS

source
Riemannian.riemann_siegel_theta — Function
riemann_siegel_theta(t)

θ(t) = arg Γ(1/4 + it/2) − (t/2) log π (continuous branch, θ(0) = 0). Chosen so that e^{iθ(t)} ζ(1/2+it) is real. θ(t) ≈ (t/2) log(t/2πe) − π/8 + 1/(48t).

source
Riemannian.hardy_Z — Function
hardy_Z(t)

Hardy's Z-function Z(t) = e^{iθ(t)} ζ(1/2 + it): real, |Z(t)| = |ζ(1/2+it)|. Its sign changes are zeros of ζ on the critical line — this is how zeros are proved to lie on the line.

source
Riemannian.riemann_siegel_Z — Function
riemann_siegel_Z(t; corrections = true)

Riemann–Siegel formula (found in Riemann's Nachlass by Siegel, 1932):

Z(t) ≈ 2 Σ_{n≤N} n^{−1/2} cos(θ(t) − t log n) + (−1)^{N−1} (t/2π)^{−1/4} C₀(p),

with N = ⌊√(t/2π)⌋, p = frac(√(t/2π)), C₀(p) = cos(2π(p²−p−1/16))/cos(2πp). Only O(√t) terms instead of O(t): this is what makes large-height computations feasible. Error is O(t^{−3/4}).

source

gram_point(n)

The n-th Gram point gₙ: θ(gₙ) = nπ (g₀ ≈ 17.8456).

Riemannian.argzeta_S — Function
argzeta_S(t)

S(t) = π⁻¹ arg ζ(1/2 + it), with arg defined by continuous variation along the horizontal line from +∞ + it (arg = 0 there) to 1/2 + it. Small and wildly oscillating: S(t) = O(log t).

riemann_von_mangoldt(T)

Smooth part of the zero count: θ(T)/π + 1 ≈ (T/2π) log(T/2πe) + 7/8.

source
Riemannian.zero_count — Function
zero_count(T) -> Int

N(T) = #{ρ : 0 < Im ρ ≤ T}, computed rigorously-in-spirit via N(T) = θ(T)/π + 1 + S(T) (argument principle). Comparing with the number of sign changes of Z on (0, T] verifies that all zeros up to height T lie on the critical line.

source
Riemannian.zeros_between — Function
zeros_between(t1, t2; refine = 4, verify = true) -> Vector{Float64}

Heights γ ∈ (t1, t2] of zeros of ζ on the critical line, found as sign changes of hardy_Z on a grid of ~refine points per average gap 2π/log(t/2π), then refined to ~1e-13.

With verify = true the count is compared with N(t2) − N(t1) from zero_count; on mismatch (e.g. a close "Lehmer pair") the grid is refined; a warning is raised if it still disagrees.

Riemannian.RH_VERIFIED_HEIGHT — Constant
RH_VERIFIED_HEIGHT

All nontrivial zeros with 0 < Im ρ ≤ 3·10¹² lie on the critical line (Platt & Trudgian, 2021). Below this height the "band" of possible zeros has width 0.

source
Riemannian.zero_free_boundary — Function
zero_free_boundary(t; method = :classical) -> σ₀

Proven zero-free region: ζ(σ + it) ≠ 0 for σ ≥ σ₀(t). By the functional equation also for σ ≤ 1 − σ₀(t).

  • :classical — de la Vallée Poussin shape, explicit constant of Mossinghoff & Trudgian (2015): σ₀ = 1 − 1/(5.573412 log t), valid for t ≥ 2.
  • :vinogradov_korobov — explicit Vinogradov–Korobov region of Ford (2002): σ₀ = 1 − 1/(57.54 (log t)^{2/3} (log log t)^{1/3}), valid for t ≥ 3; better only for log t ≳ 10⁴.

The sliver width 1 − σ₀ → 0 as t → ∞: what we can prove about the band of possible zeros approaches the full critical strip of width 1. RH says the band is the single line Re s = 1/2.

Explicit formulas

Riemannian.psi_explicit — Function
psi_explicit(x, γs)

von Mangoldt's explicit formula truncated to the zeros 1/2 ± iγ for γ ∈ γs:

ψ₀(x) = x − Σ_ρ x^ρ/ρ − log 2π − ½ log(1 − x⁻²).

Each conjugate pair contributes a wave 2 Re(x^ρ/ρ) of amplitude ~ √x/|ρ|: RH says every wave has amplitude √x, which is why the error in the PNT would be O(√x log² x).

source
Riemannian.riemann_J — Function
riemann_J(x)

Riemann's prime-power counting function J(x) = Σ_{pᵏ≤x} 1/k = Σₙ π(x^{1/n})/n.

source
Riemannian.riemann_J_explicit — Function
riemann_J_explicit(x, γs)

Riemann's 1859 explicit formula, truncated to the given zeros:

J(x) = li(x) − Σ_ρ li(x^ρ) − log 2 + ∫ₓ^∞ dt / (t(t²−1) log t),

with li(x^ρ) interpreted as Ei(ρ log x).

source
Riemannian.primepi_explicit — Function
primepi_explicit(x, γs)

π(x) reconstructed from zeros by Möbius inversion: π(x) = Σₙ μ(n)/n · J(x^{1/n}). With more zeros the smooth curve sharpens into the prime staircase.

Criteria and bounds

Riemannian.robin_ratio — Function
robin_ratio(n)

σ(n) / (n log log n). Robin (1984): RH ⇔ robin_ratio(n) < e^γ ≈ 1.78107 for every n > 5040.

robin_violations(N) -> Vector{Int}

All 3 ≤ n ≤ N with σ(n) ≥ e^γ n log log n. Unconditionally these are 26 numbers, the largest being 5040; RH is equivalent to there being no others, ever.

lagarias_holds(n) -> Bool

Lagarias (2002): RH ⇔ σ(n) ≤ Hₙ + e^{Hₙ} log Hₙ for all n ≥ 1, Hₙ the harmonic number.

li_coefficient(n, γs)

Riemannian.mertens_ratio_max — Function
mertens_ratio_max(N) -> (x, ratio)

max_{2≤x≤N} |M(x)|/√x. Mertens conjectured < 1 for all x > 1; Odlyzko & te Riele (1985) disproved it, but RH ⇔ M(x) = O(x^{1/2+ε}).

source
Riemannian.zero_density_exponents — Function
zero_density_exponents(σ) -> NamedTuple

Exponents E(σ) in zero-density bounds N(σ, T) ≪ T^{E(σ)+ε}, where N(σ,T) counts zeros with Re ρ ≥ σ, 0 < Im ρ ≤ T. RH says N(σ,T) = 0 for σ > 1/2.

  • trivial : 1 (all zeros, N(T) ~ (T/2π) log T)
  • ingham : 3(1−σ)/(2−σ) (1940)
  • huxley : 3(1−σ)/(3σ−1) (1972)
  • guth_maynard : 30(1−σ)/13 (2024)
  • density_hyp : 2(1−σ) (Density Hypothesis, conjectural)

de Bruijn–Newman

Riemannian.debruijn_Phi — Function
debruijn_Phi(u)

Φ(u) = Σ_{n≥1} (2π²n⁴e^{9u} − 3πn²e^{5u}) exp(−πn²e^{4u}), the (super-exponentially decaying, even) Fourier kernel of Ξ.

source
Riemannian.debruijn_H — Function
debruijn_H(t, z; prec = 128, h = 1/200)

Ht(z) by the trapezoidal rule (exponentially accurate for this analytic, rapidly decaying integrand), in BigFloat with prec bits because Ht(z) ~ e^{−πz/8} is tiny compared with the integrand. Returns a Float64.

source
Riemannian.heat_flow_zeros — Function
heat_flow_zeros(t; zmax = 100, step = 0.25, prec = 128) -> Vector{Float64}

Real zeros of H_t in (0, zmax]. For t = 0 these are 2γₙ (twice the zeta-zero heights). As t increases zeros repel and spread; as t decreases they attract and eventually collide and leave the real axis — Λ is the last time any collision happens.
